## Контекст проекта

osu!analytics — аналитическая платформа для osu! с профилями игроков, анализом матчей, Match Cost, Live Tracking и сравнением команд.

Основной источник данных — osu! API v2. В дальнейшем часть данных должна сохраняться локально, чтобы не запрашивать osu! API повторно без необходимости.

Сейчас основной фокус — frontend. Backend и API-контракт проектируются параллельно, но реализовываться будут после фиксации ключевых frontend-сценариев.

# Предлагаемая стратегия свежести данных

- Профиль: сразу возвращать кэшированный snapshot.
- Свежий snapshot: не обращаться к osu! API.
- Устаревший snapshot: вернуть его и поставить фоновое обновление в очередь.
- Отсутствующий или слишком старый snapshot: поставить приоритетное обновление и показать loading state.
- Историю матчей: сохранять один раз и обновлять инкрементально.
- Активный матч: опрашивать только пока он активен.
- Завершённый матч: остановить live polling и сохранить финальное состояние.
- Метаданные для frontend: `updatedAt`, `isStale`, `refreshStatus`.

Точные TTL нужно определить после проверки лимитов osu! API и ожидаемой нагрузки.
